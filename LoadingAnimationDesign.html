2. 设计说明

这是 Fluent 风格的 indeterminate progress ring： 不表示百分比，只表示「系统仍在工作」。实现上不依赖图片或 SVG， 用 CSS 圆环 + 单边高亮 + 旋转即可。

  • 完整圆环用浅色描边作轨道。
  • 仅 border-top 使用主色，旋转时形成「追逐」感。
  • 时长 0.8s、线性、无限循环——比 1s 稍快，反馈更利落，又不过于焦躁。
原则： 等待态安静、可循环、不抢主内容；错误或超时时应换成文案，不要永久转圈。

3. 规格

默认尺寸 32 × 32px
边框宽度 默认 3px；行内常用 2px；审核卡 4px
轨道色 var(--border-primary, #e0e0e0)
高亮边 border-top-color: var(--primary-color, #0078d4)
形状 border-radius: 50%
动画 spin 0.8s linear infinite → rotate(360deg)
页面占位 垂直居中 · gap: 16px · 文案 14px 次要色「加载中...」

4. 生产 CSS

.loading-spinner {
  width: 32px;
  height: 32px;
  border: 3px solid var(--border-primary, #e0e0e0);
  border-top-color: var(--primary-color, #0078d4);
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}

@keyframes spin {
  to { transform: rotate(360deg); }
}

行内缩小示例

<div class="loading-spinner" style="width:16px;height:16px;border-width:2px;"></div>

6. 使用清单

  • 新加载场景优先复用 .loading-spinner，用 inline 改尺寸，勿再写一套旋转环。
  • 默认 32px；紧凑行内 16px / 2px；强调浮层 38px / 4px。
  • 周期保持 0.8s，不要随意加快。
  • 请求需有超时/Abort，失败用错误文案，禁止无限 Spinner。
  • 可选：prefers-reduced-motion: reduce 时停动画，保留静态环或纯文案。
